## Project Description

This webpage helps visitors choose a trail based on whether they are bringing pets and their hiking experience level.

## Project Files

- PA_Flow-Control_StarterFile.html contains the webpage and recommendation form.
- PA_Flow-Control_StarterFile.css provides the webpage styling.
- PA_Flow-Control_StarterFile.js displays trail cards and selects a recommendation.

## Features

- Eight trail cards showing names, difficulty levels, and average hiking times
- Three additional trails, including leapit6717 Scenic Trail
- Radio buttons for bringing pets
- A dropdown for hiking experience
- A submit button that displays the recommended trail
- A loop to display the trail cards
- Conditional statements to select the correct recommendation

## How to Run

1. Download the project files.
2. Keep the HTML, CSS, and JavaScript files in the same folder.
3. Open PA_Flow-Control_StarterFile.html in a web browser.
4. Select your pet option and hiking experience.
5. Click Find My Trail.

## Expected Recommendations

| Bringing Pets | Experience | Recommended Trail |
|---------------|------------|-------------------|
| Yes | Low | River Walk |
| Yes | Medium | Forest Loop |
| Yes | High | Forest Loop |
| No | Low | Lake Side Path |
| No | Medium | Forest Loop |
| No | High | Rock Ridge Trail |

If no condition matches, the default recommendation is River Walk.
